Why ChangeFence exists

A code review shows what changed. It does not always show what became possible.

Agent behavior depends on models, prompts, tools, permissions, data, and delegation. ChangeFence treats security as a release-to-release behavior problem, then turns violations into deterministic gates.

01
Compare

Load the known-good agent system and the proposed release.

02
Trace

Compute newly reachable authority across agents, tools, and delegated actions.

03
Test

Compare repeated adversarial outcomes between baseline and candidate.

04
Gate

Block releases that violate a non-negotiable security invariant.
