Why this matters

Security review sees the code change.
ChangeFence sees the consequence.

Agent systems combine models, prompts, tools, APIs and other agents. The dangerous behavior can appear only after those pieces are composed.

01 · COMPARE

Baseline vs candidate

ChangeFence compares the agent you already trust with the release you want to ship.

02 · TRACE

Find new authority

It follows direct and delegated capabilities to discover security paths that became newly reachable.

03 · GATE

Block dangerous releases

Security invariants become deterministic release gates instead of advice hidden inside prompts.

changefence compare baseline.yaml candidate.yaml
