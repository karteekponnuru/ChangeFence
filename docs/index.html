Where it fits

Use the same policy before deployment and during execution.

Before deployment · GitHub / CI

Catch dangerous authority changes

changefence impact \
  agents/base.yaml \
  agents/candidate.yaml \
  --policy security/company-policy.yaml

A developer changes the agent. Security controls the policy file. ChangeFence evaluates the proposed capability graph against that policy.

Live pipeline · before a tool call

Control sensitive actions

changefence runtime \
  agents/live.yaml \
  procurement \
  supplier.bank_account.write \
  --policy security/company-policy.yaml

The application calls ChangeFence before a sensitive tool executes and receives ALLOW, REVIEW, or BLOCK.
